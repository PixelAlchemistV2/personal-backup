Privacy Policy — Personal Backup

Last updated: 30 September 2026

Personal Backup is a private backup automation with a single user: its owner. It is not offered to the public and no one else can sign in to it.

What it accesses

With the owner's permission, it uses Google's drive.file permission to create and update backup files in the owner's own Google Drive. That permission covers only files the tool created. It cannot see, read, change or delete any other file in the Drive, and it requests no other Google data — not email, contacts, calendar or profile information beyond what Google requires to sign in.

What it does with it

It uploads the owner's own backup files, encrypted on the owner's computer before they leave it, and keeps older versions for a limited time so a past copy can be restored. That is all it does.

What it stores, and where

The tool itself runs only on the owner's computer. It has no server, collects no data about anyone, keeps no logs outside that computer, and stores nothing anywhere except the owner's own Google Drive.

Sharing

Nothing is sold, shared or disclosed to anyone. No data is used for advertising, analytics or training.

Removing access

The owner can revoke the tool's access at any time from their Google Account's third-party access settings, and can delete the backup files from Google Drive like any other file.

Contact

Questions about this policy: open an issue on the project's GitHub page.
