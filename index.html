Personal Backup

A private, single-user backup tool.

Personal Backup is a personal automation that copies its owner's own files to its owner's own Google Drive each night, using the open-source tool rclone. It is not a product or a service, is not offered to anyone else, and has exactly one user: the person who runs it.

It uses the Google Drive permissions that rclone's documentation specifies (drive, docs and drive.metadata.readonly). Although those permissions reach the whole Drive, the tool only ever reads and writes its own backup folder. Files are encrypted on the owner's computer before they are uploaded.
