Personal Backup

A private, single-user backup tool.

Personal Backup is a personal automation that copies its owner's own files to its owner's own Google Drive each night, using the open-source tool rclone. It is not a product or a service, is not offered to anyone else, and has exactly one user: the person who runs it.

It asks Google for the narrowest Drive permission available, drive.file, which lets it see and manage only the files it created itself. It cannot see, open or change anything else in the Drive. Files are encrypted on the owner's computer before they are uploaded.
